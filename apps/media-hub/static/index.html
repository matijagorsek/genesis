Media

Each one opens in its own window, all sharing one browser profile, so you log in once per service and stay logged in. There is no single sign-on between these companies — each authenticates separately, and no password is stored here. The ones that need DRM use Widevine, which Firefox downloads itself if you allow it; Genesis ships none of it, which is also why these services top out at 720p on Linux for everybody.

Firefox is not installed, and it is what handles the DRM these services need.

Your own subscription. Genesis asks the provider you enter what your subscription carries and hands the stream to the player already on this machine. Your details are kept in ~/.config/genesis-media/iptv.json, readable only by you, and are sent to that address and nowhere else.
