# The sixty-second demo

"Show me Genesis" in the app menu runs this on the real maker with the real local model; nothing is
staged. The launch video is a screen recording of that entry, unedited. Six moments, in this order:

| Seconds | On screen | Said |
|---|---|---|
| 0 to 8 | The desktop. The dock badge: "on this machine", model name, "no network used". Pull the cable. | Everything you are about to see runs here. No account, no cloud. |
| 8 to 35 | The maker: "a checklist app that saves to a file". Steps appear, a preview opens. | One sentence. Watch it work. |
| 35 to 42 | A permission card, allowed once. | It asks before anything outside the project. |
| 42 to 48 | The app in the menu, opened. | Installed like any other program. |
| 48 to 55 | Meta+Shift+A, a region of the screen, a question, the answer. | Ask about anything you see. |
| 55 to 60 | Settings, Undo history, one click. | And every job can be undone. |

Record with Spectacle (Record region, no cursor effects), 1920x1080, 30 fps, on the tiny pack so the
timing is honest for CPU machines. If the make takes longer than the slot, cut the wait, never the steps.
