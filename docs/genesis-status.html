What Genesis is

A complete desktop operating system first: files, browser, terminal, settings, app store, office and media apps, with its own identity. Local language models are one integrated capability of that desktop: a launcher entry, a maker that builds what you ask for, and helpers inside the system, all running on the machine, all gated by a permission broker and undoable. It is our own distribution, derived from Fedora bootc the way Ubuntu derives from Debian: own name, image, installer, services and desktop, with Fedora's kernel, drivers and security updates inherited for free.

Fourteen CI runs. Run 10 was the first fully green pipeline; run 14 added a Rust test job and shipped the permission broker inside the image, verified by the boot test. Run 17 closed the hostname item after in-VM diagnostics showed why two earlier fixes could not work; run 21 shipped the hardware probe and verified the first-boot profile. Each failure was a distinct pipeline issue, not an image problem: podman lacking Docker's heredoc syntax, a registry pull timeout, an old podman flag, runner disk exhausted, a missing distro definition for an OS named "genesis", KVM device permissions, and a boot script typing before the shell was ready. All fixed, and a full audit removed the next ones in line: 2 GB release asset limit, private-repo artifact quota, and three bugs in the test script.
