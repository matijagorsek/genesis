<p><kbd>Meta</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> draws a box on the screen and asks about what's in it — an error, a chart, a form — with a vision model on this machine. Select text anywhere and right-click for "Ask Genesis about this". Right-click a file for what can be done with it.</p>
<p><kbd>Meta</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> listens; speak, and it sends when you pause. Replies can be read aloud; <kbd>Esc</kbd> stops one mid-sentence. A spoken request that would install, delete or send something is shown first and needs Enter, so a misheard word cannot act on its own.</p>
<figure><img src="screens/phone/05-phone-replies.png" alt="Answers from Genesis arriving as phone notifications"><figcaption>From the phone: share text starting with "ask", and the answer comes back as a notification.</figcaption></figure>
<p>With the phone paired: share any text to Genesis starting with <b>ask</b>, or send a voice note, and the answer comes back as a notification. The phone can also run a few commands — lock the screen, switch day and night, apply an update, read what's in it.</p>
