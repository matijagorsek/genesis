<p>Firefox, Dolphin, Konsole, Kate, Okular, Gwenview, Haruna and Elisa are already here. LibreOffice, Thunderbird, VLC, GIMP and Krita install themselves the first time the machine is online. For everything else there is a catalogue — fifty apps, one per need, with a sentence on why — rather than a store with forty thousand:</p>
<pre><code>genesis-apps                    # the list, with what's here marked
genesis-apps install obsidian   # one word
genesis-apps search photo       # the catalogue first, then Flathub</code></pre>
<p>Or just ask: "what do I use for notes" gets the line, "install it" gets the app. Nothing in the catalogue changes the system: apps install for you, and the image underneath is never touched. Discover is still there if you want to browse.</p>
