# Babel

A code editor for every language, with Genesis at your side.

**The Genesis rail icon** (the ring at the top of the sidebar) opens the maker. Type what should change in the folder you have open, watch the steps, answer the cards, steer, undo.

- **Ctrl+Alt+Space** anywhere: make something in this workspace.
- **Right-click in a file**: *Ask about the selection* explains code; *Change this file…* asks for a change to just that file.
- **Made here** in the sidebar lists everything Genesis built on this machine; open any of it in Babel.

Everything runs on this computer. Before anything changes outside the project, Genesis asks with a plain sentence: *Allow once* or *Not now*. Every job ends with Undo one click away.

Babel is Code-OSS underneath, so every language, debugger and extension VS Code speaks works here too.
