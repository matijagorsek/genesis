# Babel

Ein Code-Editor für jede Sprache, mit Genesis an deiner Seite.

**Das Genesis-Symbol** (der Ring oben in der Seitenleiste) öffnet den Maker. Beschreib, was sich im geöffneten Ordner ändern soll, sieh die Schritte, beantworte die Karten, steuere, mach rückgängig.

- **Strg+Alt+Leertaste** überall: etwas in diesem Arbeitsbereich machen.
- **Rechtsklick in eine Datei**: *Auswahl erklären* erklärt Code; *Diese Datei ändern …* bittet um eine Änderung nur an dieser Datei.
- **Hier gemacht** in der Seitenleiste listet alles, was Genesis auf diesem Rechner gebaut hat; öffne es in Babel.

Alles läuft auf diesem Rechner. Bevor sich etwas außerhalb des Projekts ändert, fragt Genesis mit einem klaren Satz: *Einmal erlauben* oder *Jetzt nicht*. Jeder Auftrag endet mit Rückgängig, einen Klick entfernt.

Beim Tippen schlägt Babel die nächsten Zeilen aus dem kleinen lokalen Modell vor; `Tab` übernimmt sie, die Statusleiste schaltet sie ab.

Babel ist darunter Code-OSS, also funktionieren hier jede Sprache, jeder Debugger und jede Erweiterung, die VS Code kennt.
